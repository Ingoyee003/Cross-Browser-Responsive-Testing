# Cross-Browser-Responsive-Testing

This repository contains a complete **Software Quality Assurance (SQA) project** focused on **Cross-Browser and Responsive Testing** of a web application.

The objective of this project was to ensure consistent **UI behavior, layout responsiveness, and functionality** across multiple browsers and screen sizes.

---

# Project Overview

Modern web applications must provide a consistent user experience across different browsers and devices.  
This project evaluates the application's compatibility and responsiveness through structured manual testing.

The testing focuses on identifying:

- UI misalignment issues
- Responsive layout problems
- Cross-browser inconsistencies
- Element scaling and rendering issues

---

# Testing Scope

The following modules/pages were tested:

- Homepage
- Navigation Menu
- Product Listing Page
- Product Detail Page
- Login Page
- Contact Page

---

# Testing Approach

The project followed a standard QA workflow:

1. Requirement Analysis
2. Test Planning (IEEE 829 Standard)
3. Mind Map Creation
4. Test Case Design
5. Manual Test Execution
6. Defect Reporting (Jira)
7. Test Summary Reporting

Testing Type: **Manual UI Testing**

# Defect Summary

During testing, several UI and responsiveness issues were identified:

| Bug ID | Description | Severity |
|------|-------------|---------|
BUG-01 | Navbar misalignment in Firefox | Minor |
BUG-02 | Image overflow in mobile view | Major |
BUG-03 | Product grid misalignment in Firefox | Major |
BUG-04 | Product image overflow in mobile view | Major |
BUG-05 | Button size issue in mobile Firefox | Minor |
BUG-06 | Footer text misalignment in Firefox | Minor |

All defects were tracked and documented following industry-standard practices.

---

# Key Findings

- Chrome and Edge provided consistent UI performance
- Firefox showed multiple UI alignment issues
- Mobile view revealed responsiveness problems
- Core functionality remained stable across all browsers
